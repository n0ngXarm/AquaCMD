## Functional requirements

- **AUTH**: OPC UA actions require existing explicit organization/operator authorization; denied actions invoke no network client. Source: `aqua-command-desktop/desktop/f3_network.py: _execute_secure_action; f3_opcua.py; tests/test_opcua_readiness.py`. Acceptance: Retain denied adapter call-count zero; allow a manually authorized read-only loopback action; no write capability.

- **ISOLATION**: DEMO and LIVE inventories, evidence and late callbacks cannot cross modes or write private LIVE config. Source: `aqua-command-desktop/desktop/f3_network.py: F3DeviceStore.set_demo; callback generation checks`. Acceptance: Use actual current mode IDs; switch modes before completing callback; compare LIVE values/evidence and private config bytes.

- **COMMUNICATION**: Active F3 uses local read-only API; structured committed evidence controls flow and animation; selection/navigation starts no collector. Source: `aqua-command-desktop/desktop/app.py:build_f3_network; desktop/f3_api_view.py; tests/test_f3_api_view_phase3.py`. Acceptance: Exercise active F3ApiView and API provenance, listener lifetime, explicit manual action, and no probe/collector on open/select/close.

- **PROVENANCE**: UNKNOWN is not offline; WAN/session/read/link states need structured evidence; pulses require committed events. Source: `aqua-command-desktop/desktop/f3_network.py: evidence parsing, edge render and event pulse; F3 API source contracts`. Acceptance: Flags, unverified WAN and stale/missing evidence never create verified connectivity; committed receipts alone can animate.

- **TAG_LOADING**: Private Tag import and exact mapping load work without a repository catalog; empty first run remains usable. Source: `aqua-command-desktop/desktop/app.py: scan_wincc_tags and private mapping precedence; desktop/private_runtime.py; opcua_mapping.py`. Acceptance: Inject a test-owned synthetic catalog for legacy GUI fixtures; separately check empty first run and private mapping persistence without site fixture dependence.

- **NAVIGATION**: F1/F2/F3/F6 navigation, close/reopen, owned details/settings and paged layout follow the accepted active-view contract. Source: `aqua-command-desktop/desktop/app.py; desktop/f3_api_view.py; tests/test_f3_api_view_phase3.py; desktop/tests/test_f3_production_layout.py`. Acceptance: Retain access to every configured device across pages, unclipped active controls, owner close behavior and no orphan API/listener.
